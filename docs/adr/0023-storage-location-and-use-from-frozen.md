# Storage location and use from frozen are separate

An Ingredient's usual Storage Location determines where its Stock Items are put away, but it cannot say whether freezer stock can be used without thawing: frozen peas can go straight into a pan, while a whole chicken kept in the freezer must thaw first. Keep the physical location and the Use from frozen rule separate; the latter applies only to Ingredients usually kept in the freezer, so stock moved there from elsewhere is still thawed before use.
